## Notes
- The workflow suite needs a confirmed test account. Supabase rejects undeliverable sign-up addresses, so the production test account (`e2e-owner@datalab.test`) was created pre-confirmed directly in Supabase Auth. The UI sign-up form itself is covered by the `signup` phase up to the Supabase call (validation errors and request), which then correctly returns “email address invalid” for test domains.
- Issues found and fixed by these suites: password inputs not registering with the form library (sign-in/up/reset broken), sign-in field label containing link text, anonymous catalogue access missing a function grant, builder type menu clipping off-screen, selects losing their background, a template rule pointing at the wrong question, and a lost-draft gap (now offered for restore).
- Not automated: AI answers with a real provider, Cloudinary uploads, email delivery and Paystack checkout — these require credentials that aren't configured yet. Their failure/unconfigured paths are tested.
